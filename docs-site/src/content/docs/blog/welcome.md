Welcome to the **nx-neptune** blog! This is where we'll share release notes,
feature deep dives, usage patterns, and news about bringing graph analytics to
your data lake — powered by [NetworkX](https://networkx.org/) and
[Amazon Neptune Analytics](https://docs.aws.amazon.com/neptune-analytics/latest/userguide/what-is-neptune-analytics.html).

## Get started

- **Source code:** [github.com/awslabs/nx-neptune](https://github.com/awslabs/nx-neptune)
- **Latest release:** [nx-neptune 0.6.0 on PyPI](https://pypi.org/project/nx-neptune/0.6.0/)

Install the latest release with pip:

```bash
pip install nx-neptune
```

Have questions, ideas, or want to contribute? Open an issue or pull request on
[GitHub](https://github.com/awslabs/nx-neptune) — this project is in active
development and we welcome community feedback.
