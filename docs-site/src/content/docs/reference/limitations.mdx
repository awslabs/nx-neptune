## General

- **Python ≥3.11** — the library requires Python 3.11 or higher
- **AWS credentials required** — all operations require valid AWS credentials with appropriate IAM permissions

## Session Manager

- **Athena dependency** — data lake projections require Athena; query execution time depends on data volume
- **Full graph refresh** — each import projects a fresh graph from your data lake queries, so no ETL pipeline is needed to keep the graph in sync
- **Import roles cannot carry `aws:Source*` trust conditions** — confused-deputy conditions on an import role's trust for `neptune-graph.amazonaws.com` cause imports to fail with an error that names S3 rather than trust: `ValidationException: The S3 arn … is inaccessible or your role does not have access to it`. Measured 2026-11-11 in `us-east-1` via `StartImportTask`, one run per form: `aws:SourceAccount` alone, `aws:SourceArn` scoped to `graph/*`, `aws:SourceArn` with a bare `:*`, and both keys together were all rejected, while an unconditioned trust succeeded using the same bucket, S3 policy and propagation delay. That contrast is what was measured; the likeliest cause is that the service does not supply those context keys, but other operators and ARN shapes were not tried. The bundled CloudFormation template therefore ships a separate minimal `ImportRole` whose trust is unconditioned and whose permissions reach only the staging bucket and its key, rather than relaxing the broader notebook role. If you build the role yourself, see the import-role requirements under Getting Started. Note that the library's pre-flight `check_assume_role` (`nx_neptune/clients/iam_client.py`) ignores `Condition` entirely, so an affected role passes the client check and is rejected only by the service — and the same S3-shaped error also has ordinary causes, such as a bucket outside the role's S3 permissions or a KMS problem, so rule those out too

- **athena-databricks-connector** — custom connector; must be built and deployed to your AWS account. See [installation instructions](https://github.com/awslabs/nx-neptune/blob/main/connectors/athena-databricks-connector/)
